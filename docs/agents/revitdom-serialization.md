# RevitDOM Serialization & Architecture Reference

On-demand Rung 3 reference for [CODING_STANDARDS.md](../../CODING_STANDARDS.md) governing `src/RevitDOM/` (`Synthetic.RevitDOM.*`). Consolidates [ADR 0019](../adrs/0019-cross-slice-revitdom-scope-and-engine-eviction.md) and the `10` surviving **RevitDOM** serialization ADRs (`0003`, `0009`–`0015`, `0017`, `0024`).

## 1. Cross-Slice Scope & Engine Eviction ([ADR 0019](../adrs/0019-cross-slice-revitdom-scope-and-engine-eviction.md))

- **Permitted Role:** **RevitDOM** houses cross-slice BIM infrastructure only—pure POCO models, registries, translators, **Serialization Engine**, **Identity Comparison**, **Deep Diff Comparison**, and **Alias Swapping** (see [GLOSSARY.md](../../GLOSSARY.md)).
- **Band Boundary (`FitnessRule.FourBandDependencyGraph`):** Imports only `Synthetic.Platform.{IO, Settings, Revit}` (`Features`, `Domain`, `Platform.Host`, `Platform.UI`, `System.Windows`, and `Autodesk.Revit.UI` are forbidden).
- **Evicted Single-Slice Engines:**
  - `19` standards orchestration modules (**Standards Execution Pipeline**, **Family Enforcer**, `StandardsExtractionOrchestrator`, `StandardsDiffEngine`, `StandardsExportService`, `FindReplaceService`, and DTOs) reside in [`src/Features/StandardsManagement/`](../../src/Features/StandardsManagement/).
  - Duplicate-merge orchestration (`MergeAnalysisEngine`, `NamingUtils`, and **Duplicate Candidate Harvesting** `RevitMergeDataCollector`) resides in [`src/Features/MergeDuplicates/`](../../src/Features/MergeDuplicates/).
- **Shared Review POCOs:** [`DuplicateClusterModel`](../../src/RevitDOM/Core/Models/DuplicateClusterModel.cs), [`DuplicateItemModel`](../../src/RevitDOM/Core/Models/DuplicateItemModel.cs), [`DuplicateTypeModel`](../../src/RevitDOM/Core/Models/DuplicateTypeModel.cs), [`TypeMappingModel`](../../src/RevitDOM/Core/Models/TypeMappingModel.cs), [`ParameterDiffRowModel`](../../src/RevitDOM/Core/Models/ParameterDiffRowModel.cs), and [`RecommendedAction`](../../src/RevitDOM/Core/Models/RecommendedAction.cs) stay in [`src/RevitDOM/Core/Models/`](../../src/RevitDOM/Core/Models/) because both **Duplicate Merging** and **Standards Dashboard** consume them.
- **Transitional Allowance:** [`AliasSwapEngine`](../../src/RevitDOM/Addin/Operations/AliasSwapEngine.cs) remains in `TransitionalSpecBacklog` (`TransactionPlacement`, `TransactionFailureGuard`) until Spec 5 makes it transaction-agnostic.

## 3. `StandardTypeMetadataRegistry` vs. `StandardTypeRegistry` ([ADR 0024](../adrs/0024-unified-internal-standardtyperegistry-and-composite-class-routing.md))

Consolidates all `26` canonical standard buckets and retires `ModelsToSerialize` plus `7` empty marker subclasses (`GridTypeModel`, `LevelTypeModel`, `CurtainSystemTypeModel`, `MullionTypeModel`, `FasciaTypeModel`, `GutterTypeModel`, `ViewFamilyTypeModel`):

- **`StandardTypeMetadataRegistry` (`Core/`):** Owns pure `StandardTypeDescriptor` metadata (`BucketName`, `DefaultClass`, `ModelType`, DAG `Tier` `1–6`, **Document Scope**, **Source Pane** `(GroupName, ClassName)` taxonomy with dynamic `FamilySymbol`/`HostObjType` resolvers, `LegacyBucketAliases` such as `FillRegionTypes` -> `FilledRegionTypes`, `ClassAliases`, composite key selectors, and `GetNamespaceAliasCandidates`). Directly drives headless `PocoJsonSerializer` (including legacy 26-bucket migration) and `ImportExecutionRunner.Sort`.
- **`StandardTypeRegistry` (`Addin/`):** Composes `StandardTypeMetadataRegistry` with `StandardTypeRevitBinding` (`Autodesk.Revit.DB` `Type`, `TranslatorBinding` factories registered into `ModelDispatcher`, `RootCollector` queries), `IgnoredRevitTypes`, `PendingRevitTypes`, `MatchesDisambiguators`, and `ResolveTargetElement` (disambiguating by `Category`, `FamilyName`, `ViewFamily`, `DimensionStyle`, and `Pattern.Target`). `StandardSerializationEngine` enforces **Document Scope** uniformly in `Analyze` and `ToRevit`.

## 4. Consolidated Serialization & Translator Rules

1. **Types & Standards Only ([ADR 0009](../adrs/0009-exclusion-of-physical-instance-serialization.md)):** Serialize Element Types, Base Classes, and Project Standards only—exclude physical model instances (`Wall`, `Floor`) and canvas items.
2. **Embedded Value Objects vs. Independent Graph Nodes ([ADR 0003](../adrs/0003-symmetrical-topological-dependency-sorter.md)):** Keep embedded value objects (`ColorModel`, `CompoundStructureModel`, `FillGridModel`) inline inside host POCOs; represent independent database elements (`Material`, `FillPatternElement`, `LinePatternElement`) as top-level graph nodes linked via `ElementIdModel` and scanned via [`RevitDomDependencyScanner`](../../src/RevitDOM/Core/Operations/RevitDomDependencyScanner.cs).
3. **Nested Material Assets & De Facto Sharing ([ADR 0013](../adrs/0013-nested-material-asset-models-and-de-facto-sharing.md)):** Embed `AppearanceAssetModel`, `StructuralAssetModel`, and `ThermalAssetModel` inside `MaterialModel` instead of top-level DAG nodes. [`MaterialAssetEngine`](../../src/RevitDOM/Addin/Operations/MaterialAssetEngine.cs) resolves against existing `PropertySetElement` / `AppearanceAssetElement` elements by name fallback during injection to prevent asset bloat.
4. **Hybrid Dispatcher/Translator Seam ([ADR 0010](../adrs/0010-hybrid-dispatcher-translator-architecture.md)):** Keep POCOs pure C# data containers and route Revit extraction/injection through explicit `IModelTranslator<TRev, TModel>` implementations registered in [`ModelDispatcher`](../../src/RevitDOM/Addin/Translation/ModelDispatcher.cs) (supporting one-to-many bindings such as host types -> `HostObjTypeTranslator`) behind `IStandardSerializationEngine` (`ByRevit`, `ExtractCategory`, `GatherRootElements`, `Analyze`, `ToRevit`).
5. **Generic POCO Consolidation ([ADR 0017](../adrs/0017-generic-poco-consolidation-for-parameter-driven-types.md), [ADR 0024](../adrs/0024-unified-internal-standardtyperegistry-and-composite-class-routing.md)):** Map parameter-driven `ElementType` subclasses onto `ElementTypeModel`, `HostObjTypeModel`, or `ElementModel` rather than creating empty marker POCOs; route via `(ModelType, Class)` composite keys and duplicate dynamically in [`TemplateDuplicatingTranslator`](../../src/RevitDOM/Addin/Translation/TemplateDuplicatingTranslator.cs) using `.Class` + `FamilyName`.
6. **"Filter on Extract" & Constructor Dependencies ([ADR 0011](../adrs/0011-filter-on-extract-parameter-strategy-and-explicit-constructor-dependencies.md)):** When `isTemplate == true`, [`ParameterEngine`](../../src/RevitDOM/Addin/Operations/ParameterEngine.cs) drops read-only, unset, empty-string, and invalid-`ElementId` parameters. Constructor-only data (e.g., `LinePatternElement` segments) bypasses `ParameterEngine` and lives explicitly on the POCO + translator.
7. **Deterministic Bottom-Up DAG Sorting ([ADR 0012](../adrs/0012-explicit-translator-mapping-for-topological-sorting.md)):** [`ImportExecutionRunner.Sort`](../../src/RevitDOM/Core/Operations/ImportExecutionRunner.cs) orders models deterministically by registry `Tier` (`1`: Primitives -> `2`: Materials -> `3`: Annotations/Parameters -> `4`: Categories/Filters -> `5`: System/Element Types -> `6`: Views/Templates/BrowserOrganizations; `7`/`8` fallback), then `Class`, `FamilyName`, `Name`.
8. **Magic ID Intercept & 5-Step Identity Resolution ([ADR 0014](../adrs/0014-magic-id-intercept-pattern-for-native-api-singletons.md), [ADR 0015](../adrs/0015-multi-tiered-identity-resolution-fallback-strategy.md)):** Because `doc.GetElement(id)` returns `null` for built-in negative singletons, `RevitIdentityService.ResolveElementId` intercepts singletons (`-3000010` / `"Solid"` -> `LinePatternElement.GetSolidPatternId()`, `BuiltInCategory`, `BuiltInParameter`) before resolving `Element`s in priority order: (1) `UniqueId` (including `SharedParameterElement.Lookup`) -> (2) `ElementId` -> (3) Type/Class guard -> (4) `Name` -> (5) `Aliases` (mirrored headlessly by `ElementIdModel` / `PocoIdentityService` per [ADR 0020](../adrs/0020-5-step-identity-fallback-for-elementidmodel-value-equality.md)).
