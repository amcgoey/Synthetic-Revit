# ADR 0027 - Tiered Vertical Slice Architecture and Seam CQS

Status: Accepted

## Context
As `Synthetic` consolidated legacy `Modules/` and `SyntheticShared/` code onto the multi-targeted `Synthetic.Core` + `Synthetic<Year>` build ([ADR 0028](0028-hybrid-synthetic-core-assembly-and-colocated-partitions.md)), three structural questions required hard, enforceable boundaries:

1. **Dependency Direction Across `14` Feature Slices & Platform Modules:** Without an explicit band hierarchy, features imported sibling features, cross-slice BIM models accumulated single-feature orchestrators ([ADR 0019](0019-cross-slice-revitdom-scope-and-engine-eviction.md)), and settings/UI layers coupled back into `Platform.Host`.
2. **Uniformity vs. Pass-Through Ceremony (`Direct Slice` vs. `Interactive Slice`):** Simple command utilities (`Diagnostics`, `ViewManagement`, `Worksets`) do not benefit from forced adapter interfaces, whereas stateful interactive features (`MultiModelPdfExport`, `SheetIndex`, `SharedCoordinates`, `ShadowStudy`) require Revit-free ViewModels, domain calculations, and transaction-safe Revit adapters.
3. **In-Process Seam, Wiring, and Modeless Event Boundaries:** Running on `.NET Framework 4.8` (`net48`, C# `9.0`) inside Revit's shared default `AppDomain` ([ADR 0018](0018-universal-add-in-bootstrap-manifest-routing-and-studio-deployment.md)) rules out heavy external DI/mediator/generator stacks while requiring clear rules for adapter CQS, Pure DI at command entry points, and `ExternalEvent` lifetimes.

## Decision
We structure `src/` as a **3-root, 4-band acyclic vertical slice architecture** with explicit slice classification, **Seam CQS**, **Pure DI**, and window-scoped `ExternalEvent` lifecycles:

1. **3-Root Layout & 4-Band Dependency DAG (`src/`):**
   - **Band 1 — `src/Features/<Slice>/` (`14` feature slices):** Co-located `Core/` (pure logic, models, settings, ViewModels, `I<Slice>Adapter` interfaces) and `Addin/` (Revit commands, `Revit<Slice>Adapter` implementations, WPF `.xaml` views). Sibling imports (`Synthetic.Features.<A>` -> `Synthetic.Features.<B>`) are forbidden across C# and XAML `xmlns:`.
   - **Band 2 — `src/Domain/<SubModule>/` (reserved graduation tier, `N >= 2`):** Does not exist initially. A shared domain sub-module graduates from a feature slice into `src/Domain/` only when **`>= 2` sub-modules** exist and **each sub-module is consumed by `>= 2` distinct `Features/<Slice>` modules**, with zero sibling `Domain.<A>` <-> `Domain.<B>` imports and zero dependencies on `Features`, `RevitDOM`, `Platform.Host`, or `Autodesk.Revit.*`.
   - **Band 3 — `src/RevitDOM/` (`Core/` + `Addin/`):** Cross-slice BIM representation, registries, **Serialization Engine**, **Identity Comparison**, **Deep Diff Comparison**, and **Alias Swapping** ([ADR 0019](0019-cross-slice-revitdom-scope-and-engine-eviction.md)). Imports only `Platform/{IO, Settings, Revit}` (zero `Features`, `Domain`, `Platform.Host`, `Platform.UI`, `System.Windows`, or `Autodesk.Revit.UI`).
   - **Band 4 — `src/Platform/` (`Host`, `Settings`, `UI`, `Revit`, `IO`):**
     - [`src/Platform/Host/`](../../src/Platform/Host/) ([`App`](../../src/Platform/Host/Addin/App.cs), [`RibbonManager`](../../src/Platform/Host/Addin/RibbonManager.cs), [`HostSettingsRegistrar`](../../src/Platform/Host/Addin/HostSettingsRegistrar.cs), [`RibbonItemFilter`](../../src/Platform/Host/Core/RibbonItemFilter.cs)) is the sole host composition root and is forbidden everywhere outside `Platform/Host`.
     - Remaining platform slices form an acyclic foundation: `Settings` -> `{Revit, IO}`; `UI` -> `{IO}`; `Revit` -> `{IO}`; `IO` -> pure BCL/JSON/OpenXML.

2. **Direct Slice vs. Interactive Slice & Co-Located `<Slice>/Addin/Settings/`:**
   - **Direct Slice** (`Diagnostics`, `ViewManagement`, `Worksets`, `FamilyManagement`, `MaterialManagement`): `IExternalCommand` classes in `<Slice>/Addin/Commands/` orchestrate direct Revit workflows using co-located `<Slice>/Addin/Utilities/` without forcing synthetic adapter ports or ViewModel wrappers.
   - **Direct Slice Settings Tabs:** Each slice's `ISettingModule` and **Settings Dashboard** tab ViewModel/view co-locate inside `<Slice>/Addin/Settings/` (such as [`src/Features/ViewManagement/Addin/Settings/`](../../src/Features/ViewManagement/Addin/Settings/) and [`src/Features/Worksets/Addin/Settings/`](../../src/Features/Worksets/Addin/Settings/)) and register into [`SettingsModuleRegistry`](../../src/Platform/Settings/Addin/SettingsModuleRegistry.cs) and [`SettingsTabRegistry`](../../src/Platform/UI/Addin/SettingsTabRegistry.cs) via [`HostSettingsRegistrar`](../../src/Platform/Host/Addin/HostSettingsRegistrar.cs).
   - **Interactive Slice** (`MultiModelPdfExport`, `SheetIndex`, `SharedCoordinates`, `ShadowStudy`, and transitional/dormant slices migrating in Specs 5–7): Keeps `ViewModels/`, `Views/`, `Models/`, and `Settings/` 100% free of `Autodesk.Revit.*` (`FitnessRule.InteractiveSliceSeamPurity`), organizing execution as **Harvest -> Pure Plan -> Atomic Apply** across `Core/` and `Addin/`.

3. **Single-Seam Adapter, Seam CQS & Pure DI:**
   - **Single-Seam Adapter:** Each Interactive Slice isolates all Revit database reads and writes behind one narrow port interface `I<Slice>Adapter` in `Core/Adapters/` ([`IMultiModelPdfExportAdapter`](../../src/Features/MultiModelPdfExport/Core/Adapters/IMultiModelPdfExportAdapter.cs), [`ISheetIndexAdapter`](../../src/Features/SheetIndex/Core/Adapters/ISheetIndexAdapter.cs), [`ISharedCoordinatesAdapter`](../../src/Features/SharedCoordinates/Core/Adapters/ISharedCoordinatesAdapter.cs), [`IShadowStudyAdapter`](../../src/Features/ShadowStudy/Core/Adapters/IShadowStudyAdapter.cs)), paired with one production `Revit<Slice>Adapter` in `Addin/Adapters/` and one in-memory `Fake<Slice>Adapter` in [`tests/Fixtures/Shared/`](../../tests/Fixtures/Shared/).
   - **Seam CQS (Command–Query Separation):** Adapter queries read Revit state into immutable DTOs or snapshots with zero database mutations (`LoadProjectSnapshot()`, `GetLoadedLinkedModels()`, `GetEligibleViews()`, `GetPrintSets()`). Adapter commands accept pure request parameters/objects, execute via [`DocumentTransactionExtensions`](../../src/Platform/Revit/Addin/DocumentTransactionExtensions.cs) + [`FailurePipelines`](../../src/Platform/Revit/Addin/FailurePipelines.cs), and return **Typed Outcome Objects** ([`SheetIndexExportOutcome`](../../src/Features/SheetIndex/Core/Models/SheetIndexExportOutcome.cs), [`SyncSharedSitesSummary`](../../src/Features/SharedCoordinates/Core/Models/SyncSharedSitesSummary.cs), [`RepositionLinksSummary`](../../src/Features/SharedCoordinates/Core/Models/RepositionLinksSummary.cs), [`RawFrameExportResult`](../../src/Features/ShadowStudy/Core/Models/RawFrameExportResult.cs)).
   - **Pure DI at Entry Points:** `IExternalCommand.Execute` (`CmdMultiModelPdfExport`, `CmdExportSheetIndex`, `CmdMoveLinksToSharedSites`, `CmdSyncSharedSites`, `CmdShadowStudy`, `CmdProjectStandards`) and `HostSettingsRegistrar.EnsureRegistered()` construct concrete adapters, `Platform/UI` prompt/dialog adapters, and ViewModels directly via plain constructors.

4. **Window-Scoped Single-Instance `ExternalEvent` Lifecycle (Current Implementation):**
   - `static ExternalEvent` fields are forbidden anywhere in `src/`, and ViewModels must never call `ExternalEvent.Create(...)` (`FitnessRule.ExternalEventAndDialogPurity`).
   - For modeless windows (exemplified by [`CmdProjectStandards`](../../src/Features/StandardsManagement/Addin/Commands/CmdProjectStandards.cs), and `App.OnDocumentOpen` toast dispatch), the entry command tracks a single `_windowInstance` (`Focus()` if already `IsLoaded`, clearing on `Closed`), instantiates one `IExternalEventHandler` + `ExternalEvent.Create(handler)` per window session, injects both into the window/ViewModel, and executes all Revit mutations inside `IExternalEventHandler.Execute(UIApplication)` without modal dialogs inside ViewModels or handlers.
   - Legacy `MergeDuplicatesViewModel`, `CmdDetailItemFactory`, and `AuditPurgeAllFamilies` remain allowlisted until Spec 5+, when Spec 5 will introduce a typed **`ICoalescedRevitDispatcher<TAdapter>`** seam and update this ADR alongside `MergeDuplicates`'s migration.

## Alternatives Considered
1. **MediatR / Event-Sourced CQRS:** Rejected because mediator indirection obscures call graphs, requires reflection/assembly scanning on Revit startup, and adds ceremony without value inside a single-process add-in where direct Seam CQS interfaces provide compile-time navigation and depth.
2. **Runtime IoC / DI Containers (`Microsoft.Extensions.DependencyInjection`, `Autofac`):** Rejected because sharing Revit's default runtime load context ([ADR 0018](0018-universal-add-in-bootstrap-manifest-routing-and-studio-deployment.md)) exposes external container assemblies to `AssemblyResolve` version conflicts across Revit releases (`2023–2026+`) and defers wiring errors to runtime, whereas Pure DI at entry points covers all `14` slices with zero extra dependencies.
3. **`CommunityToolkit.Mvvm` Source Generators:** Rejected because `Synthetic.Core` and Revit `2023–2024` target `net48` with `<LangVersion>9.0</LangVersion>` across multi-version MSBuild/Visual Studio toolchains; explicit [`ViewModelBase`](../../src/Platform/UI/Core/ViewModelBase.cs) and [`RelayCommand`](../../src/Platform/UI/Core/RelayCommand.cs) remain uniform across `net48` and `net8.0+`.
4. **Forcing Adapters on Direct Slices or Pre-Creating `src/Domain/`:** Rejected because one-adapter interfaces (`N = 1`) and premature shared folders add shallow indirection; Direct Slices adopt `Core/` + `I<Slice>Adapter` only when UI state warrants it, and `Domain/` waits for `N >= 2`.

## Consequences
* **Pros:** Enforces acyclic dependencies across all `4` bands (`FitnessRule.FourBandDependencyGraph` and `DomainGraduationThreshold`); keeps simple Direct Slices lean while enabling full headless **Logic Tests** for Interactive Slices (`FitnessRule.InteractiveSliceSeamPurity`); eliminates static `ExternalEvent` leaks and ViewModel Revit coupling; and localizes composition wiring in `IExternalCommand` and `HostSettingsRegistrar`.
* **Cons:** Requires maintaining explicit `TransitionalSpecBacklog` and `DormantBoyScoutAllowlist` entries ([ADR 0029](0029-isomorphic-test-mirror-and-architecture-fitness-guardrails.md)) until Specs 5–9 migrate remaining legacy interactive slices and Spec 5 ships `ICoalescedRevitDispatcher<TAdapter>`.
