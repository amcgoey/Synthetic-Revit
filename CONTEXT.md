# Synthetic

The multi-version Revit add-in designed to automate BIM tasks, manage model standards, and streamline coordination across Revit 2022 to 2026.

## Language

**Revit Version**:
The specific annual release of Autodesk Revit targeted by a project (e.g. 2024). Specified via the `<RevitVersion>` MSBuild property in project files.

**Debug Manifest**:
A Revit manifest file (`.addin`) updated with the assembly path pointing to the active build directory (e.g. `output/Synthetic/Synthetic202X.dll`), deployed to `%APPDATA%\Autodesk\Revit\Addins\<Year>\` for local execution and debugging.
_Avoid_: Local manifest, developer addin

**Local Deployment**:
The automated process of copying the **Debug Manifest** to the user-specific Revit Addins folder on local compilation to allow Revit to load the add-in.
_Avoid_: Debug installation, manual manifest copy

**Revit Journal**:
The native session log file (`journal.XXXX.txt`) generated automatically by Autodesk Revit during execution, capturing system events, API commands, exceptions, and memory logs.
_Avoid_: Session log, debug file

**Crash Dump**:
A `.dmp` file generated by Revit when a fatal crash or access violation occurs, matching the sequence number of the active journal file.
_Avoid_: Error log, dump file

**RAM Statistics**:
Memory utilization metrics periodically logged in the journal showing system InUse and Peak RAM footprints.
_Avoid_: Memory stats, RAM info
